Quick Setup Guide

Get up and running with custom Slack sounds in three easy steps.

1. Install the APK

Download the latest release APK from our GitHub repository and install it on your Android device (ensure "Install from Unknown Sources" is enabled).

2. Enable Notification Access

Open Slanotif, tap "Enable Notification Access", and check the permission toggle next to Slanotif. This is required to detect incoming Slack alerts locally.

3. Pick Channel & Sound

Type the exact name of your priority Slack channel (or DM user) in the settings panel, select a custom audio tone, and tap Save. You are all set!
