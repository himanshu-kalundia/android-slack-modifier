Android Studio project: SlackNotifLocal

How to open
1. Open Android Studio.
2. Choose "Open an existing project" and select `slack_notification_modifier/android_project`.

Notes
- This minimal project focuses on local notification-listener detection. Add a custom MP3 into `app/src/main/res/raw/` named `important_tone.mp3` (or another name and set it in Settings).
- To enable the app to detect Slack notifications, grant Notification Access: Settings → Apps & notifications → Special app access → Notification access, then enable this app.
